ملفات متجر RAI | راي
===================

الملفات:
- index.html : واجهة المتجر للزوار.
- admin.html : لوحة الإدارة المنفصلة.

طريقة الرفع إلى GitHub:
1) افتح مستودع GitHub الخاص بالموقع.
2) ارفع الملفين index.html و admin.html إلى نفس المستوى الرئيسي (Root).
3) اترك اسم index.html كما هو ليكون الصفحة الرئيسية.
4) بعد تفعيل GitHub Pages سيكون رابط المتجر:
   https://اسم-حسابك.github.io/اسم-المستودع/
5) رابط لوحة الإدارة:
   https://اسم-حسابك.github.io/اسم-المستودع/admin.html

مهم جداً:
هذه حزمة واجهة أولية وليست نظام متجر متصلاً بقاعدة بيانات حتى الآن.
المنتجات والأقسام والطلبات والرسائل تحفظ في LocalStorage في المتصفح نفسه فقط.
لذلك:
- تعديلات لوحة الإدارة تظهر في المتجر عند فتحه من نفس المتصفح والجهاز.
- الطلبات التي يرسلها زوار من أجهزة أخرى لن تصل إلى لوحة الإدارة.
- لا تعتبر لوحة الإدارة آمنة أو خاصة لمجرد أن رابطها غير ظاهر في المتجر.
- لا تستخدمها لاستقبال طلبات حقيقية أو بيانات عملاء قبل ربط قاعدة بيانات وتسجيل دخول حقيقي (مثل Supabase) وتطبيق سياسات الصلاحيات.

الخطوة التالية بعد رفع الملفات: ربط Supabase وتأمين حساب المدير، ثم تحويل الطلبات والشكاوى والمنتجات إلى بيانات مشتركة بين كل الزوار والأجهزة.
