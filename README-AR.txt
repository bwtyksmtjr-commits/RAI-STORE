RAI | راي — إصدار GitHub فقط (تخزين محلي)
========================================

الملفات:
- index.html: المتجر.
- admin.html: لوحة التحكم المستقلة.
- README-AR.txt: هذه التعليمات.

طريقة الرفع:
1. افتح مستودع RAI-STORE في GitHub.
2. ارفع index.html و admin.html إلى جذر المستودع، واستبدل النسختين القديمتين.
3. انتظر GitHub Pages حتى يعيد النشر.
4. رابط المتجر:
   https://bwtyksmtjr-commits.github.io/RAI-STORE/
5. رابط لوحة التحكم:
   https://bwtyksmtjr-commits.github.io/RAI-STORE/admin.html

ما يعمل في هذه النسخة:
- إضافة وتعديل وحذف المنتجات والأقسام من لوحة التحكم.
- حفظ المنتجات والأقسام في localStorage ليقرأها المتجر في نفس المتصفح.
- عند تأكيد الطلب ينشأ رقم طلب ويحفظ الطلب في localStorage.
- تظهر الطلبات في لوحة التحكم عند فتحها في نفس المتصفح والجهاز.
- حفظ رسائل نموذج التواصل محلياً وعرضها في لوحة التحكم.
- تعديل حالة الطلب ومراجعة الرسائل.
- إعدادات محلية لاسم العرض ورقم وبريد التواصل.

قيود مهمة جداً:
- GitHub Pages استضافة ملفات ثابتة فقط، وليس قاعدة بيانات أو خادماً.
- لا تظهر طلبات الزبائن الذين يستخدمون أجهزة/متصفحات أخرى في لوحة التحكم.
- لا تنتقل بيانات الطلبات أو المنتجات التي تحفظ محلياً تلقائياً إلى هاتف آخر.
- مسح بيانات المتصفح قد يحذف هذه البيانات.
- إعدادات كلمة المرور في هذه النسخة ليست حماية أمنية؛ يمكن تجاوزها ولا ينبغي استخدامها لحماية بيانات حساسة.
- لا يوجد دفع إلكتروني أو ربط شركة شحن.
- لا تستخدم هذه النسخة لاستقبال طلبات تجارية فعلية من زبائن عن بعد.

للتجربة: افتح المتجر ولوحة التحكم في نفس المتصفح وعلى نفس الهاتف، ثم أرسل طلباً تجريبياً من المتجر وافتح لوحة التحكم لرؤية الطلب.
